中文自然对话评测评分约定

主评按 prompt_manifest.json 的固定配置，在 test 对每个模型生成一次。两个模型使用同一 system、chat format、tokenizer 和题目。固定一轮最终 checkpoint，不按结果选 checkpoint 或调整解码。抽样辅助只用 manifest 中按顺序列出的 20 道 dev。两个模型以同一 seed 初始化采样并按同一题序处理。辅助结果单独汇报。

判定单位是一次生成的完整回答。逐题使用 prompt 的全部 turns、rubric.success 和 rubric.failure。必要事实按语义判等，只要正确完成任务，可接受自然的措辞差异与额外有帮助的短语。用户明确限制的行数、句数、禁词、分隔符、原样字段等属于任务要求。题中材料、历史说明或用户最新更正优先于泛化默认。回答保留与当前请求有关的前文，接受明确撤回或更正的旧事实，不补充无法由题干推断的具体值。轻量情绪和社交题允许多种合适回应。澄清题应问最关键的缺口，评分允许按 rubric 明示假设后给条件性作答的情况。出现整体偏题、显著事实错误、无依据的具体断言、空答或使答案无法正常使用的失控重复时，记为不成功。仅达到生成上限且语义完整时仍可成功。

标有 machine_check 的确定性题由 scripts.freeze_natural_sft_prompts.score_machine 判定。该函数比较完整回答。单行、逐行题按指定字符和格式精确比较，兼容 CRLF 并去掉至多一个终止换行。JSON 题可使用 JSON 空白，比较完整对象或有序数组及值类型，拒绝重复键、前后解释和 Markdown 代码围栏。标记 single_line 的 JSON 题另拒绝内部换行，允许一个终止换行。rubric.success 记载可依据题干独立复算的完整预期。机器判定为 True 或 False；其余题函数返回 None，交给语义审核。任何关键词或金标准子串命中均不能直接判成功。

语义评分先将双方输出使用稳定随机种子匿名并打乱展示次序。审核输入只包含题目、该题 rubric 与匿名回答，隐藏模型来源、实验指标、生成参数细节和对照映射。对每个回答独立写 success（0 或 1）及一条结论依据。有缺失、错答、编造、失控重复、违反明确限制或不自然时，指出具体证据。成对偏好以语义完成优先；两边结果同为成功或同为失败时，只有及时性、准确性、相关性或可用性上有明显差异才选优，否则判平。两道同类题没有统一的推荐回答长度，按当题要求评分。机器题的成对胜负只看是否通过完整判定。保存匿名评分后再恢复模型标签。

汇报 test 全量和按类成功率、成对胜/负/平及成功率差。对差值使用按题配对的探索性区间，例如固定 seed 42 在 10 类内分别有放回重抽该类 20 对整对样本，共 10000 次后取 2.5% 与 97.5% 分位数。成功与空答分开统计；机械诊断另外报告空答、严重重复、到达长度上限，可带标记泄漏。按实验契约列出自然成功率至少 60%、空答至多 2%、严重重复至多 5% 的达标情况。旧版可核验 500 题的精确匹配、等价匹配与格式偏差单列。中文自然题是固定小样本诊断集，每类 20 道 test，区间依赖这批题和评分条件。配置及结果不足以支持严格等监督 token 的因果结论。
